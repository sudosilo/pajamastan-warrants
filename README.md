Pajamastan Warrants

Pajamastan Warrants is a public records page in the Pajamastan set of apps. It is for anyone who wants to see the current warrants docket.

The page shows the active warrants with a count, how many are new in the last 24 hours, and when the list was last checked. Each warrant is listed as a public record entry. A backend checks the source several times a day and can send a notification when something new appears.

Live at pajamastan-warrants.vercel.app
